## Writing Principles

From content.md:

1.  **English Main Text**: Each chapter written mainly in English
2.  **Chinese Bracket Explanation**: Chinese only after important concepts in brackets
3.  **Affirmative Exposition**: Directly establish correct understanding
4.  **Content Before Form**: Begin directly with domain content
5.  **Mechanism-Based Writing**: Explain how things work - structure, function, process, cause, effect, interaction, change, risk, evidence, limitation
6.  **IELTS Boundary**: Depth matches educated general reading and IELTS-style academic texts
7.  **Test Practice After Domain**: Question-solving as later application layer

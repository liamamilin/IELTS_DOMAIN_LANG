# 雅思阅读的领域语言（Domain Language for IELTS Reading）

**在雅思主题范围内学习世界如何被英语表达** · *Lin.Mi*

一本面向雅思学术阅读与英文学术读者的领域语言读本：系统覆盖 15 个高频主题世界（科学、生态、生命、气候能源、教育、心理、健康、经济、工作、城市、农业、技术、历史考古、媒体设计），通过英文主文 + 中文括号锚点 + 浏览器交互实验，建立可迁移的学术阅读基础设施。

## 全书结构

- **Part II — Science, Nature, and Environment**（Ch 02–05）
- **Part III — Humans, Learning, and Health**（Ch 06–08）
- **Part IV — Society, Economy, and Space**（Ch 09–12）
